# X 地道双语助手 (Chrome / Edge 浏览器插件)

专为 **X (Twitter)** 打造的双向地道翻译插件：

1. **看推文（英译中 + 俚语/俗语解析）**：
   - 自动识别并意译 X 上的英文俚语（如 `fr`, `ngl`, `no cap`, `cooked`, `ratio`, `based`, `mid`, `iykyk`, `touch grass` 等）、俗语和网络梗，拒绝生硬机翻。
   - 可选附带简短的「💡 俚语/梗解析」。
   - 支持单条点击「译为中文」或开启右下角「🌐 自动翻译」边刷边译。

2. **发帖 / 评论（结合英语语境，中译地道美语）**：
   - 在回复他人推文时，自动抓取**上级推文/对话语境**，结合上下文将你的中文想法润色为地道的美式英语。
   - 支持 4 种语气切换：**日常美语**、**幽默玩梗**、**友好热情**、**专业得体**。
   - 支持一键替换输入框内容、**↩ 恢复中文**，以及快捷键 `Alt + T`。

---

## 安装步骤（Chrome / Edge）

1. 打开浏览器扩展管理页面：
   - Chrome: 地址栏输入 `chrome://extensions/`
   - Edge: 地址栏输入 `edge://extensions/`
2. 打开右上角的 **「开发者模式」**（Developer mode）。
3. 点击 **「加载已解压的扩展程序」**（Load unpacked）。
4. 选择本文件夹：`x-translator-extension`。
5. 点击浏览器右上角插件图标，填入你的 API Key（支持 DeepSeek、OpenAI、Gemini、Groq 或本地 Ollama），点击 **「测试连接」** 并 **「保存设置」**。
6. 打开或刷新 `https://x.com` 即可使用。
